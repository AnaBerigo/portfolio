# 💼 Portfólio Profissional – Ana Paula Berigo

Este projeto é um portfólio pessoal desenvolvido para apresentar minhas **habilidades**, **experiências** e **projetos** de forma organizada, visualmente agradável e profissional. Ideal para recrutadores, parceiros e colegas de área que queiram conhecer mais sobre meu trabalho.

## 📌 Objetivos

- Consolidar minha trajetória profissional
- Destacar projetos pessoais e acadêmicos
- Demonstrar domínio técnico e criativo
- Facilitar o contato com recrutadores e empresas

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (vanilla)
- Figma (para o design do layout)
- Git e GitHub

---

## 🧱 Estrutura do Portfólio

O projeto é dividido em seções, cada uma com um propósito específico:

### 🏠 Home

Breve apresentação pessoal e do que busco ou entrego como profissional.

### 👤 Sobre Mim

Um panorama do meu perfil profissional, formação, soft skills, motivações e interesses.

### 🧩 Habilidades / Stack

Lista das tecnologias, ferramentas e metodologias com as quais trabalho.

### 💼 Projetos

Exibição de projetos com descrição, tecnologias utilizadas, links e imagens ilustrativas.

### 🏢 Experiências Profissionais

Histórico de empregos ou estágios, com destaque para atividades realizadas e aprendizados.

### 📬 Contato

Esta seção foi integrada à **Home**, onde ícones das minhas redes (LinkedIn, GitHub, e-mail etc.) estão visíveis para acesso direto.

Basta clicar para entrar em contato ou conhecer mais do meu trabalho!
